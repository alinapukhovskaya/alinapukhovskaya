# Alina Pukhovskaya, PhD, MBA

Structuring institutional knowledge so AI can be trusted with it.

I work in knowledge governance and information architecture, with a focus on the foundation that makes internal AI reliable: structured content, clear ownership, and a lifecycle that tells a reader, or an agent, what to trust.

## Case Studies

**[Knowledge Governance for a Nonprofit with Semester-Based Teams](https://github.com/alinapukhovskaya/knowledge-governance-nonprofit)**
A four-gap diagnostic framework and a governance system built for an organization where teams rotate every semester. Includes a metadata schema designed for both human navigation and AI agent queries.

## Building with AI Tools

I also build with AI tools myself.

**[A Copilot Studio agent that finds unowned and outdated SharePoint documents](https://github.com/alinapukhovskaya/sharepoint-governance-agent)**
An agent that checks a SharePoint library for missing owners, overdue reviews and names that break the convention, and names who should fix each one. Covers the decisions on scope, permissions and cost, and a recommended design that uses rules for fixed checks and AI only where judgment is needed.

**[A Claude Code script that sorts a shared drive by rules before migration](https://github.com/alinapukhovskaya/file-share-cleanup-rules)**
A script that inventories a shared drive without opening files, applies 13 clean-up rules in a fixed order and logs the rule behind each decision, so owners can review the result and only unidentifiable files go to AI. Tested against an answer key on a fictional company's drive.

**[Building a Production Website with Claude Code](https://github.com/alinapukhovskaya/ai-assisted-web-build)**
How I directed Claude Code and Claude's design tool to ship an eleven-page production website end to end, including the defects the AI produced and how I caught and corrected them.

**[Working with Claude Code](https://github.com/alinapukhovskaya/working-with-claude-code)**
How I work with Claude Code in VS Code: building structured context and custom workflows to produce real artifacts, choosing the right AI tool for each job, and switching when a better one fits.
