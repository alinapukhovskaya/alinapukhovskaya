# Alina Pukhovskaya, PhD, MBA

Structuring institutional knowledge so AI can be trusted with it.

I work in knowledge governance and information architecture, with a focus on the foundation that makes internal AI reliable: structured content, clear ownership, and a lifecycle that tells a reader, or an agent, what to trust.

## Case Studies

**[Knowledge Governance for a Nonprofit with Semester-Based Teams](https://github.com/alinapukhovskaya/knowledge-governance-nonprofit)**
A four-gap diagnostic framework and a governance system built for an organization where teams rotate every semester. Includes a metadata schema designed for both human navigation and AI agent queries.
